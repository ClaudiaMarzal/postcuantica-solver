# Criptoanálisis de GGH, LWE y Ring-LWE

Trabajo de Criptología y Seguridad de los Datos (MUCC, UPV). Claudia Marzal Polop y Julia Santamarta Menéndez.

Resuelve las 45 tareas con una misma cadena: **LLL → Babai → certificado → enumeración** (esta última solo si el certificado no se cumple). Solo cambian la celosía y el objetivo de cada criptosistema.

## Uso

Necesita Python ≥ 3.10 y [uv](https://docs.astral.sh/uv/) (instala fpylll).

```
uv run solver.py ruta/a/las/tareas        # una carpeta o ficheros .txt sueltos
```
